## What

A caller makes ONE request that takes the fenced lock, applies several changes across maps, and
commits: all applied or all rejected. One redo entry or a commit marker so a restore never applies
half. Built on both the server side and the generated client side so the lock, fence token, retry
and commit are hidden from the user; the API is generated by tacplus, the implementation is
Stratum's. The identity graph adds a unique index on mapping keys (conditional write), a revision
per record and a change feed.
